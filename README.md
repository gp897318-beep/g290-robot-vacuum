A make.fun entry: the funniest excuse a robot vacuum gives for missing a spot, in 120 characters or fewer, written to `/output/entry.txt`.

> That dust bunny has lived under the bed longer than I have. Seniority wins. I respect the hierarchy.

The line is 100 characters — inside the competition gate of 1–120 characters, a single line, no trailing newline. It was picked as the winner of 10 compared variants (see `robot-vacuum-variants.md` in the work folder): the missed spot is a dust bunny under the bed with more tenure than the vacuum itself, and the machine accepts defeat with bureaucratic dignity — a surrender no other appliance could make, with the punchline landing on the last clause.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` and verifies it against the gate first.
Set `MAKEFUN_OUTPUT_DIR` to write somewhere else when running locally.
